# Staff Landing Page Verification

The signed-in Staff landing page was verified at desktop and mobile viewport sizes. It now displays an Ecology Consulting leaf-and-wordmark treatment, a personalised welcome using the current user’s first name, and a high-visibility grid of clickable colour-coded workspace cards.

The cards route users to WHS Library, EC Forms, My Projects, Timesheets, Training, Noticeboard, and BOSTA Stage 1. Administrators also see a distinct dark-green **Admin Portal** card. At the mobile breakpoint, the cards reflow into a legible vertical sequence with full-width tap targets and no horizontal overflow.
