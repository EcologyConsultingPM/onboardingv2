# WHS Drafting Workspace Requirements

## SWMS structure and presentation

The supplied SWMS reference uses a controlled-document layout rather than a free-form note. It begins with Ecology Consulting branding, a document title and project/activity subtitle, a prominent **Draft for review** status, document-control fields, and a short use and review notice. Project and PCBU details then appear in a structured green-header table with fields for the work activity, location, client/principal contractor, office/contact information, and field coordinator.

The draft workspace will therefore generate structured content sections rather than treating a SWMS as an unstructured chat response. Each AI-assisted draft will identify the activity, hazards, people exposed, current controls, recommended controls, residual-risk review points, responsible roles, and reviewer/approval placeholders. The application will visibly label generated material as a **draft for competent review**, not an approved safety document.

## Psychosocial risk assessment requirements

The supplied psychosocial risk assessment template uses an Ecology Consulting cover page followed by an explanatory page that establishes purpose, document tracking, consultation, review, and disclaimer requirements. It specifies that the assessment is used to identify, assess, and manage psychosocial hazards; that it should be completed quarterly or when there are significant work changes; and that review by the WHS Officer is required.

The psychosocial drafting workflow will prompt for consultation and work-context information, relevant psychosocial hazards, affected workers, control options, monitoring and review dates, and WHS Officer review. It will state that urgent or newly identified hazards must be reported through the organisation’s established escalation process rather than relying solely on generated text.
