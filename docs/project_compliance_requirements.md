# Project Health and WHS Compliance Dashboard Requirements

## Project health model

The Project Health Report tracks each project by client, project name, active flag, external tracker link, active task-completion percentage, current spend, remaining hours, remaining budget, health status, estimated project profitability, required project-lead check-in, comments, invoice amount, and invoicing completion. Its visible indicators distinguish **On Track** from **At Risk** and aggregate active projects, at-risk projects, on-track projects, available hours, profitability, and projects requiring follow-up.

The Admin Portal will use this model for a project-health dashboard. Project creation will capture the client contact, SharePoint project link, activity-level plan, budgeted hours, and activity start/end dates. Activity status, staff hours, progress, remaining budget, schedule position, and Senior follow-up will determine a transparent health indicator. The dashboard will show a project-level Gantt timeline based on planned activity dates.

## Staff allocation model

Each staff allocation will hold an allocation role, activity, planned dates, budgeted hours, task brief, Senior guidance, example content, numbered steps, external hyperlinks, and resource links. Staff will record hours against the allocated activity and declare it active, paused, complete, or requiring assistance. Assistance and pause reasons will be notifications to the assigning Senior; activity completion and status changes will update project health.

## WHS compliance model

The Legal and Compliance Register identifies compliance category, governing legislation/code/standard, reference, compliance requirement, evidence, responsible position, and review frequency. The workbook also tracks document reviews (file, number, topic, draft/approval state, next review date, completion) and WHS audits (scope, findings, evidence, risk, immediate action, corrective action, owner, due date, verification, monitoring, consultation, improvement triggers, endorsement, and close-out).

The WHS Manager dashboard will therefore use colour-coded due status, completion state, corrective-action status, responsible staff, and risk level. It will provide aggregate graphs for documents due, open actions, overdue items, and compliance by category, together with action requests to staff for review, drafting, completion, or amendment.
